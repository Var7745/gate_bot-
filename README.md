# GATE 2027 ECE Telegram AI Study Mentor

Automated 24/7 AI-powered study companion for **GATE 2027 Electronics & Communication Engineering (ECE)**.

## Features
- **Multimodal Circuit Doubt Solver:** Solves uploaded circuit schematics and notes using Gemini Vision.
- **Native Telegram Quiz Polls:** Interactive polls with confetti animations and step-by-step derivations.
- **Formula Sheet Engine:** High-yield formulas for all 9 ECE subjects.
- **Daily 7:00 PM Automation:** Evening study dispatches with curated YouTube classes.
- **Performance Analytics:** Tracks score and subject-wise accuracy.

## Deployment
Deployed on Render as a free Web Service with automatic keep-alive.
